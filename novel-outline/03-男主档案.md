## 二、⭐ 喜剧语域规则（本书调子的第一条纪律）

> **书名叫《装成废物这件事，我很专业》。喜剧是本书的第二核心，但男主本人绝不搞笑。**
> 完整规则见 `15-喜剧系统.md`，此处是与男主直接相关的部分。

### 他不是笑点的发出者，是笑点的**受体**

| ❌ 绝对禁止 | ✅ 正确做法 |
|---|---|
| 卖萌、装傻卖乖、说网络烂梗 | **一本正经地说真话**，而真话在那个场合杀伤力过大 |
| 主动搞笑、抖包袱、玩谐音梗 | **他没打算搞笑**，是别人的反应把它变成了笑话 |
| 自嘲式吐槽（"我这不是很惨嘛"） | **他从不评价自己的处境**，读者替他觉得好笑 |
| 插科打诨活跃气氛 | **他永远是场上最安静的那个**，而安静本身就是笑点 |

> **一句话记住：他越认真，越好笑。**
> **姜砚从头到尾不知道自己好笑。全书的喜剧，是读者笑，不是他逗。**

### 他身上的三个固定笑点结构

**① "越装越像高手"的悖论（全书最大喜剧引擎）**

他越努力装废物，别人越觉得他深不可测：
- 他故意考低分 → 有人分析"他在藏拙，为了避开某种关注"（**猜对了，但过程全错**）
- 他故意念错术语 → 教授认为这是某个古老学派的读法
- 他端着水一步不晃走完整条走廊 → 被写成小作文发上校园墙
- 他躲着不出手 → 被解读成"他在等一个值得出手的对手"

**这个笑点的高级之处：误解的方向恰好在抬高男主。读者一边笑一边爽。**

**② 他的借口都很烂，但没人怀疑**

他编谎话的水平极差（"我爷爷是赤脚医生""刚才随便看的"），**但从来没人拆穿**——因为在所有人眼里，一个这么沉默的人不至于撒谎。别人还会主动帮他把烂借口补成合理的解释。

**③ 直球输出**

他不会还嘴。被羞辱时他唯一的反应是**给出一个诊断**。这不是回击，这是他的本能——而它的杀伤力比任何回击都大。

> **写手注意**：这三个结构在前 30 章必须各出现至少两次，把调子立住。

## 三、男主的人格魅力设计

### 让男性读者爽的四根支柱

1. **信息碾压，不是武力碾压。** 他赢在"知道对方不知道的事"。每一次对抗的爽感来自**"原来他早就看出来了"**。
2. **忍得有理由。** 他不是圣父式忍让，他是在**执行一个计划**。读者知道他在忍什么、忍到什么时候会放开——**这份"等待感"本身就是追读引擎**。
3. **每次出手都在流血。** 抵押机制让每一次高光都带着痛感，读者会替他心疼，而不是麻木。
4. **他一直在往上走。** 校园 → 医界 → 豪门 → 地下 → 八脉 → 组织 → 三百年。**层层都有更强的人，他层层都赢得很难。**

### 让女性读者认可的四种时刻

1. **他救人不挑人。** 救过讨厌他的人、打过他的人、反派的家属。他的原则是"能救就救"，与私人恩怨无关。
2. **他尊重女性的专业。** 温栖迟是外科规培医生，他从不越过她替她做决定；裴雾是病理主治，他会老老实实等她的报告。**他把女性当同行，不当被拯救者。**
3. **他不解释，但他会兜底。** 被误会时他不辩，但真出事的时候他一定在。**"他从来不说，但他每次都在"** ——这是全书对他最高的评价。
4. **他身上明显缺了一块。** 吃不出味道、想不起母亲的脸、右手会突然握不住东西。**女性角色是通过发现这些缺口才真正对他动心的——不靠撩，靠"心疼 + 敬重"。**

### 明确禁止的写法

| ❌ 禁止 | 原因 |
|---|---|
| 油腻撩妹、开黄腔、故意挑逗 | 与人设完全不符，且会毁掉女性读者盘 |
| 无理由装逼、主动去打脸 | 他的动机是"藏"，主动出击违背逻辑 |
| 被女性长期保护、靠女人解决主要问题 | 违反大男主定位 |
| 遇事就发火、失控 | 他的核心特质是过度自控，失控只能在全书 3 个指定节点出现 |
| 自贬式谦虚（"我什么都不会啦"） | 他的伪装是**沉默与迟钝**，不是嘴上示弱 |
| **耍宝、卖萌、自嘲** | **见第二节。这条是新增的最高优先级红线** |

## 四、⭐ 扮猪吃老虎场景模板（20 类 · 逐层升级 · 严禁重复）

> **通用铁律**：每一次"吃虎"必须满足三个条件——
> ① 他**被迫**出手（有人要死、有人碰了他的底线、不出手会暴露更多）
> ② 他出手后**付出了代价**（暴露风险 / 抵押 / 树敌 / 身体损伤）
> ③ 打脸的**手段每次不同**，禁止套用"众人嘲笑 → 男主出手 → 众人震惊"的固定三段式

### A 组 · 实力型（8 类 · 主线打脸）

|---|---|---|---|---|---|---|

| 2 | **旁观式** | 卷一 | 走廊里的路人 | 提前 40 分钟看出病人要出事 | **他不救，只写了张纸条塞给护士**——功劳全是别人的，但事后有人查监控 | 留下影像证据 |

### 反重复检查表（写手每写一次"吃虎"必须对照）

- [ ] 这次的**触发原因**和上一次不同吗？（救人 / 保命 / 护人 / 换资源 / 被逼 / 误会 / 主动）
- [ ] 这次的**手段**和之前 19 类都不同吗？
- [ ] 这次**有人替他挡了功劳**，还是他自己出面？（应交替出现，不能连续三次同一种）
- [ ] 这次的**观众**是谁？（同学 / 医生 / 豪门 / 地下 / 八脉 / 组织）观众必须逐层升级
- [ ] 这次他**付出了什么**？没有代价的打脸一律删掉
- [ ] **⭐ 打脸之后写的是"众人震惊"还是"具体而离谱的反应"？** 前者一律返工，见 `15-喜剧系统.md` 第六节

### ⭐ 打脸后的反应写法（强制）

**禁止**："全场震惊""鸦雀无声""倒吸一口凉气""如遭雷击"。

**改写成具体、离谱、可传播的反应**：
- 有人默默把手机举了起来
- 有人小声问旁边的人"他刚才说啥"
- 有人第二天开始模仿他走路
- 有人回去把这件事写成小作文发在校园墙上
- 有人当场掏出笔记本开始记
- 教授回办公室翻了三本书，没找到依据，更慌了

**具体的反应比"震惊"有效十倍，而且好笑。**

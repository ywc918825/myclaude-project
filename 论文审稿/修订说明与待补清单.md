1. **修复了推导链断裂**。原 5.3 节的"最终得分"用的是成果积分 //s//ₖ，与前两步的标签权重 //W// 是两条互不相干的通路。

2. **修复了量纲不一致**。原式 `W = α·Σ(s·w) + β·W_old` 把无上界的"积分"和 [0,1] 的"权重"直接相加。
   现引入 //S//max,t 归一化，并写成标准的一阶 EWMA 形式（α + β = 1），补充了 α = 0.7 对应记忆长度 ≈ 3.3 个周期的说明。

4. **修复了归一化的三个缺陷**：归一化区间由 [0,100] 改为 [20,100]（避免最低分用户雷达图退化为尖刺）；

## 四、想要带数据的雷达图

`图3生成器.py` 同时能生成两种图，取决于里面的 `SERIES` 有没有数据：

- **留空**（当前状态）→ 输出维度体系图，只有坐标系与维度名
- **填入得分** → 输出带数据的能力雷达图，含三条系列、数据点与图例

用法：打开脚本，把顶部数据区的三行注释取消，填入系统导出的 16 个归一化得分
（式(7) 的结果，范围 20–100，**顺序必须与 `DIMS` 一致**），然后：

```
python3 图3生成器.py
```

得到新的 `fig3.png` / `fig3.svg`，替换文档里的图 3 即可。曲线用实线／虚线／点线区分，
黑白印刷下也能分辨。

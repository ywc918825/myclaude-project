## 二、查出并已修复的问题（7 项）

### ❶ 全文引号是 ASCII 半角 —— 严重，已修

| | 修前 | 修后 |
|---|---|---|
| ASCII 双引号 `"` | **21,584 个** | 0 |
| ASCII 单引号 `'` | **414 个** | 0 |
| 全角 `“ ”` | 0 | 10,792 对 |
| 全角 `‘ ’` | 0 | 207 对 |

**为什么严重**：七猫、番茄这类平台的正文对白必须用全角引号。半角引号在移动端阅读器里显示为直立细线，行距和字距都会崩，编辑第一眼就会判定"没排版"。

**怎么修的**：写了逐行交替替换的转换器，跑之前先验奇偶——全卷 0 行引号不成对，所以转换是安全的，不会出现"开引号配错闭引号"。转换后复验：左右引号数量完全相等。

> 这是我自己的疏漏。书旗版当初做过引号转换，七猫版从 001 写到 070 我一直直接敲的半角，中途没有回头检查过。

## 六、我给这一卷的实话

**它现在的问题不在硬指标上。**

硬指标全过了，而且是实跑过的。真正的风险在两个地方：

**第一，前三章的爽点强度。** 001 的第一次出手是"她站了四十分钟"——这是一句很好的话，但它的爽感是**冷的**。七猫的读者在第一章要的是热的。第一次真正意义上的打脸落在 008（当着全班反证清白），第 8 章对免费平台来说偏晚。

**如果编辑反馈"前面不够抓人"，最快的改法是把 008 那场戏往前挪到 004–005**，而不是在 001 加特效。

**第二，这一版的主角很冷。** 他六个月记了 17 笔账，每一笔都在算划不划算。这是这一版的设计核心，也是它最大的赌注——赌读者会为"一个精确的人"停留，而不是只为"一个爽的人"停留。

041、031、013 三章（开锅、暖宝宝、军训）是全卷最暖最好笑的三章，**如果要调整节奏，往前挪它们比往前挪打脸更安全**。

这两条我没有替你改，因为它们不是缺陷，是这一版明确交换掉的东西——改了就不是这一版了。

## 二之二、第三轮：把承诺提到第 11 字，给账本加一个往上走的数

打脸挪完之后重读，还有两处会真实拖数据。都改了。

### ❶ 第一章前 600 字没有任何承诺 —— 已修

**实测（改前）：** 报到处的冲突从第 613 字才开始，第一次出手在第 1,089 字。
前 600 字是纯身份介绍，读者不知道这本书要给他看什么。

**改法：把结尾那段八岁回忆整体挪到章首。** 不是新写，是移位——

- 原本在章末：八岁那年他爸擦针，教他"看出来别说"、教他记账、说"想起你的人多了，就有人来找你"
- 移到章首之后，第一行是「**姜砚八岁就学会了一件事：看出来，别说。**」
- 章末保留最狠的部分：十一岁那年他爸死在马路对面那栋楼里、第七扇窗开着、八年没人回答

**实测（改后）：** 金手指在**第 11 字**，代价预告在**第 137 字**。
字数 2226 → 2198（顺手裁掉四处冗余叙述），对白率 40% 守住硬线。

> 代价是第一次出手从 49% 位置退到 56%。这一步是划算的：
> **读者知道他能，才会为他不能而着急。** 改前那 600 字读者不知道，只是在看一个考砸的人办手续。

### ❷ 前十一章账本只往下走 —— 已修

逐章拉过主角的"获得"：001 无 / 004 无 / 005 只有方教授的关注 / 007 三千一个月 /
008 无 / 009 一张表 / 010 多一个月。**十一章里只有一样能换成数字的东西。**

而暴露值 1→2→7→9→11→12 一路摆在读者眼前。
**只有代价有仪表盘，收益全是形容词**——在免费平台上这读起来不是扮猪吃虎，是主角在受苦。

**改法：快钟从单行缺口改成双行。**

| 章 | 改前 | 改后 |
|---|---|---|
| 004 | 四万二，一分没有 | **挣到：零。缺口：四万二。** |
| 007 | 四万二，一分没有 | **挣到：零。缺口：四万二。**＋"从明天晚上六点起，一天一百" |
| 013 | 缺口：四万零五百 | **挣到：三千。**＋缺口 |
| 014 | 缺口：四万零五百 | **挣到：三千。一个月了，还是三千。**＋缺口 |
| 049 | 要还四万九千八 / 已还三千二 | 中间补上**手里攥着的：两万零三百二十七** |

「挣到：零。缺口：四万二。」在 004 和 007 各出现一次——**这是故意的**，
三天过去数字一分没动，本身就是内容。与「那天晚上，姜砚在便签本上写：」×12 同类。

### ❸ 005 章末在最大爽点之后立刻降温 —— 已修

改前末句「而他的账上，四万二一分钱都没少」是情绪收，不是钩子。
全卷最强的一场戏刚打完，追读动力应该是新威胁。

改后收在方教授那句话的回响上：

> **“下节课带把尺子来。我给你看点别的。”**
>
> ——一个老师开始想教他了。
>
> 这不是好事。

（同时删掉章中间吴茂复述这句话的那一轮，避免同一句在一章里出现两次。）

## 二之三、第四轮：数字瘦身与试读区改名

### ❶「X 秒」是全卷最重的口癖 —— 已修

规格是每章精确数字 ≤3。实测下来真正的问题不是数字多，是**同一个节拍标记反复出现**：

| | 改前 | 改后 |
|---|---|---|
| 「X 秒」总数 | **167** | **68** |
| 其中「两秒」 | **88** | 20 出头 |
| 每章平均 | 2.4 次 | 1.0 次 |

「巷子里安静了两秒」「吴茂想了两秒」「他看了三秒」这类整行只是一个停顿标记的句子，
在手机上连着出现一百多次就是卡顿——**中文网文本来一行就是一个节拍，再标一次"两秒"是重复计时**。

**怎么删的**（两轮，可复现）：

1. 第一轮按形式设上限：安静／想／看／沉默／停／站 每种全卷不超过 4 次，超出的整行删除 —— 删 69 行
2. 第二轮针对试读区（001–016）逐行过，把剩下的格式化节拍删掉或改写 —— 改 30 处

**保留的都是数字本身就是内容的**：
「我转过来才三秒」「三秒你能看清三个数？」（002 的核心问答）、
「三个地方，三条线，十秒钟」（004）、「两秒里，四样东西」（011）、
009 那一整段以八秒为节拍的注视、015 的倒数「一秒。两秒。」。

删完有 4 章掉到 1800 字以下（009 / 020 / 028 / 037），**补的全是对白不是叙述**，
顺带把这四章的对白率也抬上去了。

### ❷ 试读区四个标题在书架上点不动 —— 已改

七猫的目录页是真实的决策界面。改的是免费试读窗口里最不可点的四个：

| 章 | 改前 | 改后 | 理由 |
|---|---|---|---|
| 004 | 骭 | **他念错了一个字** | 生僻字，多数读者念不出、搜不到，部分机型字体不一定渲染 |
| 008 | 一句话 | **校医自己摸不到** | 太抽象，且与 005「三句话」、011「三个字」撞型 |
| 009 | 报名表 | **你左肩脱过臼** | 原题只说了道具，没说戏 |
| 012 | 队尾 | **一米七五** | 开场那个"我穿 175"是全书人设的缩影，比"队尾"具体得多 |

**「骭」这个字留在正文里**，方教授还是会在黑板上写它、还是会说"你们大概一辈子都用不到"——
只是不拿它当书架上的招牌。

**没有动 020 之后的标题。** 「查」「借」「还」「手」「门」这些单字标题确实抽象，
但读者读到那里已经在书里了，不是在书架上挑；而且 061「手」／062「门」／069「他推开了那扇门」
是设计好的三级递进，改了反而散。

## 三、第一轮查出并已修复的问题（7 项）

### ❶ 全文引号是 ASCII 半角 —— 严重，已修

| | 修前 | 修后 |
|---|---|---|
| ASCII 双引号 `"` | **21,584 个** | 0 |
| ASCII 单引号 `'` | **414 个** | 0 |
| 全角 `“ ”` | 0 | 10,766 对 |
| 全角 `‘ ’` | 0 | 207 对 |

**为什么严重**：七猫、番茄这类平台的正文对白必须用全角引号。半角引号在移动端阅读器里显示为直立细线，行距和字距都会崩，编辑第一眼就会判定"没排版"。

**怎么修的**：写了逐行交替替换的转换器，跑之前先验奇偶——全卷 0 行引号不成对，所以转换是安全的。转换后复验：左右引号数量完全相等。**重构之后又复验了一次，仍然相等。**

> 这是我自己的疏漏。书旗版当初做过引号转换，七猫版我一直直接敲的半角，中途没有回头检查过。

### ❷ 正文出现 2 个半角逗号 —— 已修

- `“去年那个,”她说` → `，`
- `那扇门,我也没有钥匙` → `，`

（另有 6 个半角逗号在金额千分位 `￥42,000` `23,200.00` 里，属正常写法，保留。）

### ❸ 两章重名 —— 已修

原第 023 章和第 059 章都叫「第十七排」。前者改为「**别去**」（对应老邢那句"第十七排你别去，因为我也不去"）。重构后是第 022 章和第 058 章。

| 「赵姨这辈子最远只去过附一」 | 后一处改写 |

## 七、我给这一卷的实话

**硬指标全过了，而且是实跑过的。**

上一轮我说过两条风险。现在只剩一条。

**已经解决的：前面爽点太晚。** 第一次真正的打脸从第 8 章提到第 5 章，从第 15,700 字提到第 9,800 字。

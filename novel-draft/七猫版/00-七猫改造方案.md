## 一、三条主干的具体解法

### 主干①：给姜砚一个每天都在滴答的目标 —— **双钟**

原书只有一个目标：查清八年前父亲怎么死的。
这是**慢变量**——没有期限、没有每日进度、读者不着急。

七猫版加两个钟：

| | 钟 | 期限 | 读者感受 |
|---|---|---|---|
| **快钟** | **屺和堂三个月后被收铺** | 90 天，每天都在走 | 钱。急。看得见 |
| **慢钟** | **那栋灰楼年底动工拆除** | 一年 | 证据要没了 |

**快钟是这一版的发动机。**

- 房东通知涨租并要求三个月内补齐欠款，否则收铺
- 叔公六十三岁，铺子没了他没地方去，而且**药柜最上面那一格里的东西不能搬到别处**
- 姜砚是自费生，学费还欠着一半

**关键设计：他唯一值钱的本事，正是他绝不能用的那个。**

原书：他不出手，因为会被杀父仇人发现 → 抽象、遥远，读者不着急。
七猫版：他不出手，**下个月叔公就没地方住** → 具体、紧迫，读者替他着急。

危险仍然在（暴露＝被贺庭章那边发现），但现在**每一次"忍住"都有一个立刻能算出来的价格**。

而"算价格"恰好是姜砚本来的性格——他是个计算型的人。**人设不用改，只是把他的算盘摆到台面上。**

---

### 主干②：把"忍住"改成"忍不住" —— **暴露值**

给读者一个看得见的仪表盘。

**规则（每章都要能对上）：**

| 动作 | 收益 | 暴露值 |
|---|---|---|
| 只说"我看见"级别的话（不给方法） | 小 | **+1** |
| 给出可验证的指标（量双臂、查 CA19-9） | 中 | **+2** |
| 当众动手/当众下结论 | 大 | **+5** |
| 用到只有姜家才有的东西（古称、图引） | — | **+10** |
| 编一个烂借口把事情按回去 | — | **−1** |
| 让别人替他背功劳 | — | **−2** |

**阈值：**
- 累计 **20** → 有人开始私下打听他
- 累计 **50** → 有人去教务处调他的材料
- 累计 **80** → 名字进入不该进的名单

姜砚自己在便签本上记这个分。**读者跟他一起数。**

这一条同时解决三件事：
1. 每一次出手都变成"我要不要花这笔钱"，读者会替他心跳
2. "扮猪吃虎"从一种性格变成一个**有仪表盘的游戏**
3. 打脸有了成本，爽感反而更强

## 三、写作硬指标（每章交稿前自检）

| 项 | 标准 |
|---|---|
| 字数 | **1800–2200**，不得超 2300 |
| **对白率** | **≥ 40%**，第 1–5 章 ≥ 45% |
| 段落 | 平均 ≤ 15 字，单段不超过 60 字 |
| **章末** | **必须留钩**：疑问句 / 未完成动作 / 别人的一句话。禁止收束式抒情结尾 |
| 专名 | 每章新引入 ≤ 2 个 |
| **精确数字** | 每章 ≤ 3 个。保留记忆点（103 块、312、四下），其余模糊化 |
| 视角 | 只有姜砚 |
| 暴露值 | 每章结尾必须能对上账 |
| 内心独白 | **能改成对话的一律改成对话**——姜砚心里想的，让吴茂问出来 |
